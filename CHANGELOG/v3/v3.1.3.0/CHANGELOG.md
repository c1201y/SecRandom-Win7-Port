# v3.1.3.0

## 🚀 主要更新

- 新增 **计时器**，支持倒计时、秒表、时钟三大板块，并支持小窗置顶显示
- 新增 **批量设置头像**，选择文件夹后按名称/编号自动批量匹配成员与奖品头像
- 新增 **Omni TTS** 云端语音引擎，支持 OpenAI、FishAudio、小米 MiMo、Gemini，MiMo 支持音色克隆
- 新增 **插件系统**，支持从插件市场安装、本地 `.srpx` 安装、启用/禁用/卸载，插件可注册浮窗按钮
- 新增 **语音批量生成音频缓存** 与 **清空语音缓存**，导入名单后可离线播报
- 新增 **无边框窗口边缘拖拽缩放**（实验性，Win7 实机表现待验证）

## 🐛 修复问题

- 修复 独立模态窗口（计时器等）整窗被遮罩压灰的问题
- 修复 导入名单“选择文件”按钮误触导入流程的问题（点名/抽奖/引导页）
- 修复 名单导入重名时点击“自动重命名”无反应的问题（点名/抽奖）
- 修复 浮窗设置页无法打开的问题
- 修复 插件市场验签公钥缺失导致市场刷新失败的问题

## 🔧 其它变更

- 插件市场公钥内嵌于程序集，不再依赖外部文件
- 更新源与反馈链接指向 Fork 仓库
