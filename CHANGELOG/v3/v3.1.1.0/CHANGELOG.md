# v3.1.1.0

## 🚀 主要更新

- 恢复 Edge TTS 语音合成功能
- Windows 7 使用内置 NLayer MP3 解码与 NAudio waveOut 音频播放，不再依赖 Windows Media Player 或 WMP COM
- 增加 Windows 语音播放与抽奖音乐的内置音频后端
- 将 EdgeTtsSharp 源码并入仓库，简化 Windows 7 版本构建与发布
- 优化 Windows 7 兼容性，避免使用不可用的系统音频组件
- 引导窗口去除系统装饰
- 主窗口与设置窗口去除原生边框按钮
- 增加透明区域手动边缘缩放

## 🐛 修复问题

- 修复 Edge TTS 音频帧解析错误导致语音文件生成失败的问题
- 修复 Edge TTS 在 .NET 6 下 WebSocket 连接与请求头兼容问题
- 修复系统 TTS 不可用时无法自动回退至 Edge TTS 的问题
- 修复旧版配置中的中文语言名称无法反序列化的问题
- 修复英文系统环境下反馈模板测试失败的问题
- 修复 GitHub Actions 发布时缺少 `win-x64` 运行时还原配置的问题
- 修复拖动缩放窗口时出现闪烁的问题
- 修复重复启动时 Win7 不支持透明背景导致全屏黑色或白色窗口遮挡桌面的问题
- 修复重复启动提示出现多余遮罩层的问题，窗口贴合对话框并以圆角区域裁剪显示
- 修复设置搜索框因本地化元数据缺失导致的 `NullReferenceException`
- 修复安全设置保存密码失败时没有反馈的问题
- 增加密码不一致、密码过短、当前密码必填的本地化错误提示
- 统一密码最小长度校验为 6 位
